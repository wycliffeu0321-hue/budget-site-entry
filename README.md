# HomeLedger — Household Budget
A complete household budget site that runs offline in a browser: dashboard, transactions, budgets, bills, savings goals and reports, with real working controls and local persistence.
Open app/index.html in a browser, or serve the folder. Hand in with: MAKEFUN_OUTPUT_DIR=out node main.ts
